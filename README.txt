MELTY FILE（めるてぃーふぁいる） v1 - iPhone対応版

PIXEL ARCHIVE v2 をベースに、AMU INFIRMARY v7 と同等の基本機能・レイアウト・デザインを維持したまま改修しました。

【公開方法（GitHub Pages）】
1. ZIPをiPhoneの「ファイル」アプリで解凍します。
2. 中の index.html をGitHubリポジトリの一番上（root）へアップロードします。
   （既存の index.html は置き換えて Commit changes します）
3. Settings > Pages > Deploy from a branch > main / (root) で公開します。
4. 表示されたURLをSafariで開き、共有ボタン →「ホーム画面に追加」すると、アプリのように使えます。
   ※ index.html 1枚だけで動作します（アイコンも内蔵）。

【今回の主な変更】
- 名称を MELTY FILE（めるてぃーふぁいる）に変更
- 設定 > デザイン設定
  ・テーマカラー8種 + メインカラーを自由に選択
  ・アクセントカラー / 背景色 / 文字色を個別に指定（「自動」で戻せます）
  ・ナイトモード
  ・フォント9種 + 好きなフォント名を入力（端末のフォント / Google Fonts）
- 音楽リンクをSpotify限定から「任意のURL」に変更
  YouTube / Apple Music / SoundCloud / ニコニコ動画 / その他。https:// は省略可。
  サービスを自動判定してボタン表示（例：YouTubeで開く）。javascript: など危険なURLは登録できません。
- iPhone向け改善
  入力欄の拡大ズーム防止（16px）、タップしやすいボタンサイズ、ノッチ/ホームバー対応、
  検索中にキーボードが閉じない、画面切替時に先頭へスクロール、
  画像タップで拡大表示、大きな写真の自動縮小（設定で変更可）、
  共有シートからのバックアップ保存、ホーム画面追加対応
- 不具合修正
  下部メニューのアイコンが白で見えない問題 / 画像削除時に入力中の文字が消える問題 /
  キャンセルしても画像削除がメモリに残る問題 / 世界観・関係性の詳細が一覧で見えない問題 など

【維持している機能】
キャラクター登録・編集・削除・検索 / 画像複数追加 / タグ / 自由項目 / メモ /
関係性（A↔B選択）/ 世界観 / 音楽（関連キャラ複数選択）/ 資料室（キャラ別フォルダ・画像）/
ホームのイラスト表示 / ステッカーBOX / バックアップ書き出し・復元

【データの引き継ぎ】
- 以前の PIXEL ARCHIVE（pixel_archive_v1）または AMU INFIRMARY（amu_infirmary_v2）のデータが
  同じサイト（同じ github.io ドメイン）にある場合、初回起動時に自動で引き継ぎます（元データは消しません）。
- 別のドメイン/端末へ移すときは、旧アプリでバックアップを書き出し、
  MELTY FILE の設定から「バックアップを読み込む」で復元してください（旧形式のバックアップも読めます）。

【保存について】
- データはアクセスしたブラウザ内（IndexedDB）に保存されます。端末間の自動同期はありません。
- iPhoneのSafariは、長期間開かないサイトのデータを自動削除することがあります。
  「ホーム画面に追加」して使い、定期的にバックアップを書き出してください。
- デザイン設定はlocalStorageに保存され、バックアップにも含まれます。
